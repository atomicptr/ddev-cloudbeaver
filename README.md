# DDEV Cloudbeaver

DDEV addon for using Cloudbeaver

## Installation

```bash
$ ddev add-on get atomicptr/ddev-cloudbeaver
```

## Usage

- `ddev Cloudbeaver` - Opens Cloudbeaver in your browser (`https://<project>.ddev.site:8979`)
- `ddev describe` - Confirm service status and used ports
- `ddev logs -s cloudbeaver` - Check the logs
